# .github: Organization Policies and Defaults

Second-Hand Tigers is a volunteer initiative developing career-development and project-skills material for engineering students and early-career engineers. This repository holds the policies and default files that apply to every repository in the organization.

## What is here

| Where | What |
|---|---|
| [Wiki](https://github.com/second-hand-tigers/.github/wiki) | The organization's policies: [AI Use Guidelines](https://github.com/second-hand-tigers/.github/wiki/AI-Use-Guidelines), [Management of Private Information](https://github.com/second-hand-tigers/.github/wiki/Management-of-Private-Information) (including the privacy policy), the licensing summary, and the organization use policy |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | How contributions are licensed and what to confirm before submitting |
| [`LICENSE.md`](./LICENSE.md) | The license for this repository's written content |

## About default files

GitHub shows the `CONTRIBUTING.md` in this repository to anyone opening an issue or pull request in an organization repository that does not have its own. Default files are not included when a repository is cloned or downloaded, so each repository also carries its own copies of `CONTRIBUTING.md` and its license.
